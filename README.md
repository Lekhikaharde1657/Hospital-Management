# 🏥 Hospital Management System

### Good Health & Care Hospital | Vajreshwari

A simple and user-friendly Hospital Management Website + Java Project made for college project. This project helps hospital to manage Patients, Doctors and Appointments easily.

### ✨ Live Website:
https://lekhikaharde1657.github.io/Hospital-Management/

---

## ✨ Features

- **Add Patient** - Patient Name, Age & Disease add karu shakto
- **View Doctors List** - 4 Doctors with their Specialization & Fees
- **Book Appointment** - Patient, Doctor, Date nivdun Appointment book hote
- **Live Dashboard** - Doctors, Patients, Appointments Count live disto
- **Patients & Appointments List** - Sagale records khali list madhe distat
- **Clear All Data** - Ekach click madhe sagala data clear hoto
- **Mobile Friendly** - Mobile var pan ekdam chhan chalte
